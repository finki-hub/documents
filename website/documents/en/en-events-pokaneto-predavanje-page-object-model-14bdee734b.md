# Покането предавање: Page Object Model – ФИНКИ

На ден 08.05.2018 (вторник) од 15:00 до 17:00 часот во просторија Амфитеатар на ФИНКИ ќе се одржи покането предавање од страна на вработени во QA секторот на фирмата ITLabs.

Тема на предавањето е: Page Object Model: Practical implementation with Selenium а предавачи се: Венета Милошева, Senior QA Engineer и Дијана Брлиќ, QA Engineer.
