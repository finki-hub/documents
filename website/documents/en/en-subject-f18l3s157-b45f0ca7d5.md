| 10. | Objectives of the course programme (competences) | Introduction to the organization and manipulation of data stored in data warehouses, as well as the basic operations and algorithms for working with data warehouses. The student will be able to model data warehouses, organize and manipulate data stored in data warehouses, and prepare analytical reports based on that data. |
| 11. | Course content | Basic concepts of data warehouses; Data warehouse architecture; Data flow in data warehouses; Data warehouse modeling; Organization of data in a star schema data warehouse; Data organization in a data warehouse snowflake schema; Hypercubes and multidimensional databases; Technologies for data analysis (OLAP); Extensions to the SQL standard for OLAP needs; The relationship between operational databases and data warehouses; Automatic data updating in data warehouses, data cleansing and aggregation (ETL processes); Organization of distributed data warehouses; Analysis of very large datasets; The practical implementation will cover an examination of leading data warehousing tools and technologies. |
