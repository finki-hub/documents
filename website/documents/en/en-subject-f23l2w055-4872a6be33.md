| 10. | Objectives of the course programme (competences) | The goal of the course is for the student to become familiar with the fundamentals of various media: audio, graphics, video, and animation, and to understand the different properties of each. The student should learn about the various formats and become proficient in using them for different applications to create multimedia content. As a higher-level objective, the student should be able to develop a small multimedia product using the techniques and methods learned. |
| 11. | Course content | Lectures:  1. Introduction to the subject  2. Application of multimedia  3. Development of multimedia projects  4. Text  5. Graphics  6. Video  7. Animation  8. Working with video software  11. Creating a project |
| 12. | Learning methods | Lectures using presentations, interactive lectures, exercises (using equipment and software packages), teamwork, case studies, guest lectures, independent preparation and defense of a project assignment and a seminar paper. |
