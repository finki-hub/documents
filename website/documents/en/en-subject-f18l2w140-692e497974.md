| 10. | Objectives of the course programme (competences) | To introduce students to the paradigm of generic programming. To familiarize them with abstract data types,  Creating template classes and functions. To develop skills for using data collections (vectors, rows, lists,  sets and dictionaries). In the end, students are expected to be able to apply the concepts of object templates.  Software development oriented toward modeling a specified problem in a robust object-oriented program.  Students will be introduced to software development techniques in an integrated development environment. |
| 11. | Course content | Generic programming, abstract data types, generic functions, generic classes, collections with linear access, collections with random access, maps, refactoring, basic concepts of software design patterns, threads and concurrency. Development environment, integrated development environment. |
| 12. | Learning methods | Lectures supported by slide presentations, interactive lectures, practical classes (using equipment and software packages), teamwork, case studies, guest lecturers, independent preparation and defence of a project assignment and seminar paper, and learning in an electronic environment (forums and consultations). |
