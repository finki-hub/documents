| 10. | Objectives of the course programme (competences) | The goal of the course is for students to become familiar with unstructured and semi-structured data types, their organization and storage, as well as techniques for their manipulation and processing. Students will also be introduced to NoSQL databases, modern databases that do not adhere to the relational model and are used in distributed and cluster environments. Special emphasis will be placed on practical knowledge of one of the NoSQL databases. |
| 11. | Course content | Lectures:  1. Introduction to semi-structured data. ObjectExchangeModel (OEM). Introduction to XML. Structure of XML documents.  2. Data Schemas - DTD  3. Data Schemas - XMLSchema  4. Recommendations for transforming EER models into XML data schemas  5. Manipulation of XML documents. Using XPath to navigate through XML documents.  6. Manipulating XML documents via XQuery, setting up simple queries, and using user-defined functions  7. Introduction to NoSQL databases. An introduction to structuring, storing, and manipulating data organized through NoSQL databases.  8. Map-Reduce methodology for parallel problem solving  9. Data aggregation and aggregate data models as the foundation of NoSQL databases  10. Document-based databases and key-value databases  11. Column-family and graph databases  12. Most commonly used NoSQL databases and their application in various domains and applications    Practical Classes:  1. OEM examples. Introduction to XML. Examples of XML document structure (elements, attributes)  2. DTD Data Schemas  3. XML Schema Data Schemes  4. Transformation of EER models into XML Schema  5. Examples of navigating XML documents with XPath  6. Manipulating XML documents with XQuery  7. Review of Relational Algebra  8. Problem Solving in Map-Reduce  9. Solving problems with aggregate models  10. Project Task  11. Project Task  12. Project Task |
