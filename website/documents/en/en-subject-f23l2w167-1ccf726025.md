| 10. | Objectives of the course programme (competences) | The goal of the course is to familiarize students with the basic problems and ways of solving them for different types of user interfaces and user interaction. Upon completion of the course, the student is expected to demonstrate knowledge of the basic types of user interaction and the principles for their design, and to be able to independently develop interactive applications using programming tools in accordance with the learned principles. |
| 11. | Course content | Lectures:  1. User behavior. Introduction, a brief history, user behavior when working with interactive systems, frameworks for describing user behavior.  2. Content organization in interactive systems. Organizational schemes, structural organization, templates for organizing and displaying data.  3. Navigation. Problems. Principles of good navigation. Navigation models. Templates for designing navigation in interactive systems (navigation models, combining layout and navigation models, label placement, animated transitions)  4. Screen Organization. Basic concepts (visual hierarchy, visual flow). Techniques for grouping and arranging elements. Gestalt principles. Screen organization patterns.  5. Forms and Data Entry. Principles of form design. Types of data entry elements and controls. Form design templates (relationships between elements, element values, etc.).  6. Actions and Commands. Rendering actions. Representation of actions. Templates for actions and commands (displaying actions, improving action selection, information on long-term actions, working with sequences of actions)  7. Interaction with data lists. Information architecture. Interaction models.  8. Social Media Interaction. Principles and methods of communication on and with social media. Interaction models.  9. Interaction in mobile devices. Features that determine interaction in mobile devices. Interaction models.    Practical Classes:  1. Introduction to technology for implementing user interface templates. Examples related to the basic features.  2. More advanced concepts and possibilities of technology for implementing user interface templates. Examples that illustrate these concepts and possibilities.  3. Implementation of navigation design patterns in interactive systems. Implementation of examples in which they are used.  4. Implementation of screen organization templates. Implementation of examples in which they are used.  5. Implementation of examples involving forms, data entry elements, and controls.  6. Implementation of examples that include templates for actions and commands.  7. Implementation of the interaction patterns for data lists and illustration of examples where they are applied.  8. Enabling social media interaction. Implementation of interaction models.  9. Implementation of characteristic examples of interaction in mobile devices using interaction models. |
