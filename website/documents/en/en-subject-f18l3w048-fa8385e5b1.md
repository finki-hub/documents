| 10. | Objectives of the course programme (competences) | The goal of the course is to equip students to create applications for microcontrollers and to work with input/output. Students will also be able to implement and manage software configuration. |
| 11. | Course content | (1) Using an environment for developing, writing, compiling, and debugging a program for embedded systems (1) Understanding the hardware aspects of embedded system behavior (1) Performance, power consumption, and cost of embedded systems  (2) Basic software techniques for embedded systems applications (1) Debugging techniques for embedded systems applications  (1) Writing programs that perform multiple input/output operations (1) Software queues for buffered data streams  (1) Writing programs for periodic interrupts and clock signals (1) Writing programs for monitoring physical properties, using sensor data, and controlling actuators (1) Structured approach to writing complex applications for embedded systems (1) Creating programs that use state machines and RTOS for embedded system applications  (1) Safety of Embedded Systems Software |
| 12. | Learning methods | Lectures using presentations, interactive lectures, exercises (using equipment and software packages), teamwork, case studies, guest lectures, independent preparation and defense of a project assignment and a seminar paper. |
