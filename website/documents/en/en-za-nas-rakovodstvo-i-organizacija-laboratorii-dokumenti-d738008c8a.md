# Документи – Лаборатории – ФИНКИ

[Laboratories](https://finki.ukim.mk/en/za-nas/rakovodstvo-i-organizacija/laboratorii/)
[Documents](https://finki.ukim.mk/en/za-nas/rakovodstvo-i-organizacija/laboratorii/dokumenti/)

The Faculty has a large number of appropriately equipped laboratories that meet all standards for conducting practical and theoretical teaching.

The list of laboratories includes:

- High Performance Computing Laboratory
- Grid, Parallel and Distributed Processing Laboratory
- Server Laboratory
- Advanced Web Technologies Laboratory
- Intelligent Robotics Laboratory
- System on Chip Design Laboratory
- Internet and Innovative Technologies Laboratory
- Semantic Technologies Laboratory
- Software Engineering and Advanced Programming Techniques Laboratory
- Information Systems, Multimedia and Visualization Laboratory
- Mobile and Multimedia Applications Laboratory
- Laboratory for Mobile and Ubiquitous Semantic Experience – LaMUSE
- SMART Laboratory for Interactive Teaching and Collaboration
- CISCO Computer Networks Laboratory
- CUDA Teaching Center by NVIDIA
- FORTINET Information Security Laboratory
- NOKIA Mobile Application Development Center
- Regional Social Innovation Center
- Eco-informatics Laboratory
- Intelligent Systems Laboratory

The Faculty also has a larger number of appropriately equipped laboratories and computer classrooms for teaching in the lower years of study.
