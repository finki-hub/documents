# Оглас за пријавување на тутори за лабораториски вежби – ФИНКИ

Потребни се тутори за изведување на лабораториските вежби за следните предмети со број на непокриени групи:

|  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | **Course** | **Непокриени групи** | | Advanced databases | 3 | | E-commerce and mobile commerce | 3 | | Operating Systems | 12 |   Сите тековни студенти кои ги имаат положено предметите, може да се пријават за тутори на максимум 6 групи.  Притоа, кандидатите треба да испратат маил до [arhiva@finki.ukim.mk](mailto:arhiva@finki.ukim.mk) со наслов Пријава за тутор.  Во мејлот треба да се наведат за предметите за кои се пријавува кандидатот, број на индекс и да се наведе  колку максимум групи би можел/а да покрие (сумарно за сите пријавени предмети).  Кандидатите ќе бидат рангирани според оцената на предметот, просекот и бројот на освоени кредити, по соодветниот приоритет.  Рокот за пријавување е до **03.03.2023 до 16:00 часот.** |
