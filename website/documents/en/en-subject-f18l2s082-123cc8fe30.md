| 11. | Course content | Development environments. Event-driven programming. Application creation wizard and form designer. User interface controls for displaying information to the user, controls that trigger events, text input controls, controls for displaying and changing state, controls for displaying information in lists, and controls for grouping other controls within an application. Event generation and handling. Timer-based events. Graphical user interface for advanced applications, localization (l10n) and internationalization (i18n). User menus, toolbars, and status bars. Creating user-defined controls. Threads and inter-process communication, resource sharing, and content exchange between applications. Creating installation packages. |
