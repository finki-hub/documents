# Web Developer for Erasmus NGO Website – ФИНКИ

---

## Description

NGO Creators of the Future is looking for a motivated and creative web developer to build a fully functional website for our Erasmus-focused NGO. The website will represent our organization, showcase projects and opportunities, and help us communicate with students, partners, and participants across Europe.

We are looking for someone who can independently develop and deliver a complete modern website — from design and frontend to backend functionality and deployment.

What you will work on

• Building a complete responsive NGO website from start to finish
• Creating modern and user-friendly frontend pages
• Developing backend functionality and database integration
• Implementing application/contact forms and admin functionality
• Optimizing website performance and mobile responsiveness
• Connecting the website with social media and external platforms
• Deploying the website and preparing it for public use

Required Skills

• Strong knowledge of HTML5, CSS3, and JavaScript
• Experience with React, Next.js, or similar frontend frameworks
• Backend development knowledge (Node.js, ASP.NET, PHP, or similar)
• Experience with hosting and website deployment
• Understanding of responsive and accessible web design
• Knowledge of Git/version control
• Ability to independently complete a full project

Nice to have

• Experience building NGO, Erasmus, or event-related websites
• Basic UI/UX design skills
• Knowledge of SEO and website optimization
• Experience with CMS systems like WordPress

Your day-to-day

• Planning and developing website features
• Creating frontend and backend components
• Testing and debugging website functionality
• Collaborating with the NGO team on content and structure
• Delivering a production-ready website with documentation

What We Offer

• Opportunity to build a real-world international NGO project
• Flexible work schedule
• Practical portfolio experience
• Networking opportunities through Erasmus activities
• Possibility for long-term collaboration on future projects

Please send us your CV in English to creatorsofthefuturemk@gmail.com with the subject: ‘Web Developer internship’.
