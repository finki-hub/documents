# Поднесување молби – ФИНКИ

In **[the application system](http://molbi.finki.ukim.mk)** The following are enabled:

- Request to Enroll More Than 35 Credits
- Request for payment in installments
- Request to Enroll in a Course Without Fulfilling a Prerequisite

**The deadline for submission is until 12.02.2024.**
