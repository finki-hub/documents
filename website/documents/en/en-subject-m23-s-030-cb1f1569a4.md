| 10. | Objectives of the course programme (competences) | The goal of the course is to introduce students to software quality management techniques. The areas covered by the course include the software quality management process, software testing, software testing objectives, test selection techniques, and metrics, test design, test execution, analysis of data obtained from tests, test lifecycle.  Upon completion of the course, the student will be able to demonstrate knowledge of the concepts of the software quality management process.;  - to design tests for various types of applications;  - to conduct the testing;  to interpret the test results and apply them to improve the quality of the software. |
| 11. | Course content | Software quality and the software quality management process. Software development and the testing life cycle. Approaches to software testing. Types of tests in the software development phases. Techniques for selecting tests based on coverage criteria (input value ranges, execution logic, syntax-based testing). Test planning and documentation development. Tools for automated test execution. |
