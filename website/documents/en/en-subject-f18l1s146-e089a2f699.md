| 10. | Objectives of the course programme (competences) | Upon completion of the course, students are expected to gain introductory knowledge for developing websites with modern design using HTML and cascading styles. Candidates are expected to:  1. They demonstrate a basic understanding of the importance of good website design.  2. Demonstrate practical knowledge of web design technologies and be able to apply that knowledge to basic website design.  3. To communicate using terminology specific to this field.  4. Critically evaluate examples of websites. |
| 11. | Course content | Introduction to the WWW, History of the WWW, browser basics. Structure of web pages with HTML5 tags, properties, history of tags and systems. Compatibility with earlier versions of HTML and XHTML. Cascading Styles – CSS3, properties, length units, selectors, pseudo-elements, box model, positioning, margins, page layout organization – methods  Introduction to design, methodologies, site structure and architecture, navigation, functionality, writing for the web, typography, color, design concepts, the golden ratio, contrast. Basics of usability, basics of accessibility. |
| 12. | Learning methods | Lectures supported by slide presentations, interactive lectures, exercises (using equipment and software packages), teamwork, case studies, guest lecturers, independent preparation and defense of a project assignment and a seminar paper, and learning in an electronic environment (forums, consultations). |
