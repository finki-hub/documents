| 10. | Objectives of the course programme (competences) | To study the methods used to programme modern robots and to examine  the programming languages and platforms that enable robot programming.  Students are introduced to tools currently used for robot programming: the Robot Operating System, development environments for programming microcontrollers, and other software tools. |
| 11. | Course content | Evolution of robotics technologies.  Microcontrollers as controllers of robotic systems.  Microcontroller programming.  Robot programming with ROS.  Robot configurations and component interconnection.  Programming processes using asynchronous calls.  Programming real-time control processes. |
