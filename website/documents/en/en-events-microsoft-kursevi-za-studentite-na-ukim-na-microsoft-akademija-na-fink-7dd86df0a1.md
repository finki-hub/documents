# Microsoft курсеви за студентите на УКИМ на Microsoft академија на ФИНКИ – ФИНКИ

Microsoft академијата на ФИНКИ организира Microsoft курсеви за студентите на УКИМ од областа на Веб технологии, администрација на сервер и бази на податоци чија цел е оспособување на кандидатите за развој, имплементација и одржување на софтверски апликации.

По успешно завршување на секој од понудените курсеви, освен здобиеното знаење, кандидатите ќе се стекнат со:

- Академски сертификат за познавање на соодветната Microsoft технологија и
- дополнителни 2 кредити на студиските програми на ФИНКИ за секој завршен курс.

*Напомена: Максималниот број на кредити кои може да се добијат од екстракурикуларни активности на ФИНКИ е 6 кредити.*

![_mg_9776.png](https://finki.ukim.mk/wp-content/uploads/2026/06/mg_9776.png)

Курсевите ќе се одвиваат во модерно опремени лаборатории, каде секој од студентите ќе има можност практично да работи на материјалот кој ќе се предава.

 Цената за курсевите е:

- 10.000 денари за еден запишан курс со можност за плаќање на 2 рати (соодветствува на 2 ЕКТС кредити).
- 18.000 за два запишани курса со можност за плаќање на 3 рати (соодветствува на 4 ЕКТС кредити).
- 24.000 денари за три запишани курса со можност за плаќање на 4 рати (соодветствува на 6 ЕКТС кредити).

Во рамки на академијата се нудат следниве 7 курсеви:

**Web Applications**

1. Developing [ASP.NET](http://asp.net/) MVC Web Applications
2. Developing Microsoft Azure Solutions

**Windows Server**

1. Installing and Configuring Windows Server 2012
2. Administering Windows Server 2012
3. Configuring Advanced WIndows Server 2012 Services

**SQL Server**

1. Querying Microsoft SQL Server
2. Administering Microsoft SQL Server Database

Дополнително се нудат и 3 курсеви од Microsoft Office пакетот.

**Microsoft Office**

1. Excel Expert
2. Word Expert
3. Sharepoint Expert

Цената на овие курсеви е:

- 6.000 денари за еден запишан курс (соодветствува на 2 ЕКТС кредити).
- 11.000 за два запишани курсеви со можност за плаќање на 2 рати (соодветствува на 4 ЕКТС кредити).
- 15.000 денари за три запишани курса со можност за плаќање на 3 рати (соодветствува на 6 ЕКТС кредити).

Минималниот број на пријавени кандидати за активација на секој од понудените курсеви е 6. Курсевите ќе започнат во втората половина на Јануари 2017 во договор со кандидатите.

**Сите заинтересирани кандидати потребно е да се пријават**[**here**](https://goo.gl/forms/T8laZbI6RGPyXLak2)**, најдоцна до 15.01.2017.**
