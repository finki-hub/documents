| 10. | Objectives of the course programme (competences) | Introduction to virtualization as a paradigm for creating virtual computer systems through software virtualization of hardware components. Discussion of the various aspects of virtualization, the technologies and techniques involved in the process, as well as the benefits and drawbacks that arise in the virtualization process. |
| 11. | Course content | Virtualization concepts. Types of hypervisors. Virtualization theory, benefits in a server environment, application virtualization. Virtual machines. Types of CPU virtualization. Virtualization of physical machines. Processor and memory in a virtual environment. Paravirtualization. Xen. New virtualization architectures. Virtualization of data storage devices. Dynamic and static storage. Cloning and copying. Redundancy, backup, cloning, and templates. Snapshot and checkpoint. Device management in a virtual environment. Resource sharing. Network virtualization. Virtualization orchestration. Security in a virtual environment. Server consolidation. Virtual machine migration. |
