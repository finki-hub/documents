# Hash Code 2021

Netcetera Macedonia, Web Factory и Google Developers Group Skopje ве поканува во своjот виртуелен хаб на 25.02.2021 да се приклучите на Hash Code 2021. Hash Code е тимски, програмерски натпревар организиран од Google, за студенти и професионалци од целиот свет. Тимовите се состојат од 2-4 членовии имаат слобода во избор на програмскиот јазик. Натпреварот е поделен во две рунди, првата е квалификациска, а втората е финална рунда и ќе се одржи во Април. За прв пат годинава настанот ќе се одржи целосно онлајн / виртуелно. Регистрирајте го вашиот тим најдоцна до 17-ти февруари и изберете еден од виртуелните хабови – Netcetera или Web Factory.

Регистрација на тим: g.co/hashcode Избор на hub: &lt;http://g.co/hashcode/hubs&gt;

Дознајте повеќе на официјалниот Facebook настан &lt;https://www.facebook.com/events/1290910181272988/&gt;
