# Покането предавање од Farhan Shahid од Allocate Software

На 25-ти април во 10:00 часот во амфитеатарот на ФИНКИ ќе се одржи покането предавање на тема “Web Application Security”. Предавањето ќе го одржи Farhan Shahid, Technical Architect од Allocate Software.

Ве молиме доколку присуствувате да го потврдите вашето присуство на следната [анкета](http://courses.finki.ukim.mk/mod/choice/view.php?id=55675).

Повеќе детали околу агендата и биографијата на предавачот можете да видите на следниот [линк.](https://oldsite.finki.ukim.mk/sites/default/files/upload_file/skopje_-_web_application_security.pdf)
