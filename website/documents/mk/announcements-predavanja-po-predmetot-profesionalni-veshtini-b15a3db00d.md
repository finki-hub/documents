# Предавања по предметот професионални вештини

Од утре, четврток, 03.10.2013 година ќе започнат предавањата по предметот Професионални вештини. Предавањата ќе се одржуваат според распоредот на часови. Утре со настава почнува Група 5 во 8 часот.
