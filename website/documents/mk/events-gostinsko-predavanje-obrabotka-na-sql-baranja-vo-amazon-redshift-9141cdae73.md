# Гостинско предавање: Обработка на SQL барања во Amazon Redshift

### Обработка на SQL барања во Amazon Redshift

**Гостинско предавање од член на Алумни борд.**
Предавањето ќе се одржи во **среда од 18:00 часот**, во **амфитеатарот на Машинскиот факултет**.

![Мартин Миленкоски](https://finki.ukim.mk/wp-content/uploads/2026/06/thumbnail_29_mg_martin_1.jpg)

**Апстракт:**
Во оваа презентација ќе зборуваме за архитектурата и начинот на обработка на SQL барањата во Amazon Redshift. Ќе ги прикажеме уникатните предизвици со кои се соочуваат модерните складишта на податоци и нивните решенија. На крај, ќе дадеме осврт на моменталните трендови во областа на процесирање на големи податоци.

**Биографија:**
Мартин Миленкоски е софтверски инженер во Amazon Web Services, каде што работи на развојот на сервисот за бази на податоци Amazon Redshift, со фокус на процесирање и оптимизација на SQL барања. Тој исто така работи на интеграција на Redshift со open-source формати како Apache Parquet и Apache Iceberg. Претходно има работено во Facebook и Swisscom.

Мартин има дипломирано на ФИНКИ во Скопје и е магистер по компјутерски науки од EPFL во Лозана. Добитник е на наградата „Инженерски прстен“.
