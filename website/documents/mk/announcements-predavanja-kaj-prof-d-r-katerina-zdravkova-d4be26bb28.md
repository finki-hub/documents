# Предавања кај проф\. д\-р Катерина Здравкова

Почитувани студенти, наставата по предметите: „Компјутерски апликации“ и „Професионална етика“ кај проф. д-р. Катерина Здравкова нема да има во текот на оваа недела. Предавањата ќе започнат наредната недела, од 21.09.2012 година, согласно распоредот на часови.
