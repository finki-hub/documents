# Web Developer Intern

Motion Source is looking for a creative, driven developer to join our web team. You’ll work on modern web applications for real clients, collaborating closely with experienced senior developers who’ll help you grow technically and professionally. Whether your interest lies in frontend, backend, or both — this is the ideal environment to sharpen your skills and launch your career.

WHAT YOU’LL GAIN
• Paid internship with hands-on project involvement from day one
• Mentorship and direct guidance from senior developers
• Experience contributing to real client-facing web applications
• A supportive, knowledge-sharing culture that values quality code
• Team-building events and professional networking opportunities
• A strong pathway to long-term employment upon successful completion

WHAT YOU’LL LEARN & WORK WITH
• Modern frontend development with HTML5, CSS3, and JavaScript (ES6+)
• Frontend frameworks — React or similar, depending on project stack
• Backend development concepts using C# and ASP.NET
• RESTful API design and integration
• Responsive and accessible web design principles
• Version control workflows using Git
• SQL and relational database fundamentals
• Code review practices and writing clean, maintainable code

WHAT WE’RE LOOKING FOR
• Student or recent graduate in Computer Science or a related field
• Basic knowledge of HTML, CSS, and JavaScript
• Familiarity with any frontend framework or .NET technologies is a plus
• Understanding of responsive design principles
• Good English skills and the ability to communicate clearly within a team
• A genuine passion for building things and a drive to keep improving

YOUR DAY-TO-DAY
• Assist in developing and maintaining web applications
• Contribute to both frontend and backend development tasks
• Participate in debugging, testing, and performance optimization
• Collaborate with designers and senior developers during project delivery
• Write clean, well-structured code and follow established best practices
