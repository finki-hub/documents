# Конкурс за стипендија за “Fulbright NATO Security Studies”

Почитувани,

Ве информираме дека добивме известување од Министерството за образование и наука дека Американската амбасада го објави конкурсот за аплицирање за стипендија во “**Fulbright NATO Security Studies**“.

Подетални информации во врска со стипендијата можете да најдете на следниот линк: **&lt;https://mk.usembassy.gov/fulbright-nato-security-studies-award/&gt;**
