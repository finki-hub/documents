# Sorsix Spring Internship 2026 \(Web Programming\)

The Sorsix Spring Internship 2026 (Web Programming) is a hands-on, on-site internship where you’ll code alongside experienced engineers and learn what it actually takes to ship in a production environment (clean code, teamwork, reviews, real deadlines).

This isn’t a “watch and learn” programme – it’s built as a pathway into full-time roles. Historically, most selected interns transition into full-time positions within 12 months.

👩‍💻 Who should apply
Year II–IV students or postgraduates in Computer Science / Informatics / Computer or Software Engineering

✅ What we’re looking for
Solid Java or Kotlin foundations, good English, confidence, curiosity, and strong ownership

🛠 Tech stack
Angular SpringBoot PostgreSQL

📅 Apply by 15 February
📩 Send your CV to jobs@sorsix.com
Subject: Web Programming Internship

If you want your next semester to turn into a real career start – this is your shot.
