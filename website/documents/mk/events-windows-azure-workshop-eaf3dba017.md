# Windows Azure Workshop

MSP Windows Azure Workshop е дводневна (25 и 26.06) работилница за вовед во платформата Microsoft Azure, организирана од страна на Finki Tech Клубот (кој е дел од програмата на Microsoft Student Partner) и поддржана од страна на [Microsoft CEE](https://www.facebook.com/MicrosoftCEE/) и [Факултет за информатички науки и компјутерско инженерство (ФИНКИ)](https://www.facebook.com/FINKI.ukim.mk/). Првиот ден ќе виде вовед во Cloud концептот и практична примена во Microsoft Azure платформата, која ќе биде оддржана од страна на Хајан Селмани од компанијата [HASELT](https://www.facebook.com/HASELTofficial/). Додека пак вториот ден ќе се посвети на Machine Learning алатките што се достапни во Windows Azure и нивна примерна, оддржана од страна на Андон Драгоманов од компанијата [MCA](https://www.facebook.com/MCA-151862404856575/).
Концептот е замислен 2 часа теоретски (предавања), и 4 часа практичен (работа во лабораторија) дел во текот на двата дена. Во практичниот дел ќе биде зададена вежба стекната од предавањата, практичниот дел ќе биде изведен во лабораториите на ФИНКИ. Вкупно 20 студенти ќе земат учество во работилнцата.
