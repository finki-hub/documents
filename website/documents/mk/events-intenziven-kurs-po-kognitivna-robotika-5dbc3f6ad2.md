# Интензивен курс по Когнитивна роботика

Почитувани студенти,

Од 14-21.04.2015 ќе се одржи интензивен курс по Когнитивна роботика. Инструктор ќе биде проф. Ханс Дитер Буркхард од Хамболт Универзитетот во Берлин, Германија. Местата за курсот се ограничени.

Заинтересираните се повикува да се пријават на следниот линк &lt;http://robotika2015.b1.finki.ukim.mk/#/apply&gt;

Секоја од темите е пропратена со интензивна практична настава и програмирање во Java/NetBeans.
